Arden Sheets privacy policy

Last updated: 2 November 2026

Arden Sheets is a private tool used only by its owner, Anselm (Jay) Okojie, with his own Google account. It has no other users.

What data it accesses

With the owner's consent, it uses the Google Sheets permission (https://www.googleapis.com/auth/spreadsheets) to read and update cells in spreadsheets the owner already has access to. It does not request any other Google permission.

How the data is used

Spreadsheet contents are read and written only to carry out the owner's own tasks (for example, reading a request from a task sheet and writing back its status). The data is not sold, shared with third parties, used for advertising, or used to train AI models.

Storage and security

The sign-in token is stored only on the owner's own computer, in a protected user setting, and is never published or shared. The tool keeps a small local log of which sheet rows it has processed.

Google API Services User Data Policy

Arden Sheets' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions.
